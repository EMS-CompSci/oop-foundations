## Key vocabulary

| Term | Definition |
|------|---------|
| Inheritance | The feature where a **child class** is **derived** from a **parent class**, such that it encapsulates everything the parent class encapsulates with the option of encapsuate further data or methods.|
| Association | A dependency relationship between two classes, such that one class is contained within aother. |
| Composition | A type of association wher the containing class is fully 'owned' by the containing class. |
| Aggregation | A type of association wher the containing class is not fully by the containing class. |
| Protected | The access modifier which gives scope to objects of the same family. |
| Overriding | The feature which allows for a child class to redefine a (virtual) method of the parent. |
| Virtual Method | A method which can be overridden. |
| Virtual Class | A class which contains a some virtual methods. |
| Polymorphism | The implementation of different behavious of objects of related classes, achieved by overriding. |
